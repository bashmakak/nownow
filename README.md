# NowNow

Сайт микрообучения: один курс даёт одно ключевое знание за 30 минут.

Это демо-версия без сервера. Прогресс, закладки и заметки хранятся в браузере посетителя.

## Что внутри

- Главная страница, каталог из 24 курсов по 12 темам, страницы тем и курсов.
- Плеер урока из шести блоков: зачем, идея, пример, практика, проверка, ключевое знание.
- Кабинет: продолжить урок, серия дней, статистика, карточки ключевых знаний, заметки, выбор темы оформления.

## Запуск на своём компьютере

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev      # сайт откроется на http://localhost:5173
npm run build    # готовая сборка появится в папке dist
```

## Публикация

Сайт публикуется на GitHub Pages автоматически при каждом изменении ветки `main`
(файл `.github/workflows/deploy.yml`). В настройках репозитория должно быть включено:
Settings → Pages → Source → GitHub Actions.

## Где что лежит

| Папка | Содержимое |
| --- | --- |
| `src/data` | Темы и курсы: тексты уроков, вопросы, карточки |
| `src/pages` | Страницы: главная, каталог, темы, курс, плеер, кабинет |
| `src/components` | Шапка, подвал, карточки, логотип, иконки |
| `src/lib` | Хранение прогресса и общие диалоги |
| `src/styles.css` | Дизайн-система: цвета, шрифты, компоненты |

Чтобы добавить курс, допишите объект в один из файлов `src/data/courses-*.js`.
Тема появляется в каталоге, когда в ней есть минимум два курса.
