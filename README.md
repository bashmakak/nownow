# NowNow

Сайт микрообучения: один курс даёт одно ключевое знание за 30 минут.

Это демо-версия без сервера. Прогресс, закладки и заметки хранятся в браузере посетителя.

## Что внутри

- Главная страница, каталог из 66 уроков по 33 темам в пяти разделах, страницы тем и уроков.
- Плеер урока из шести блоков: зачем, идея, пример, практика, проверка, ключевое знание.
- Кабинет: продолжить урок, серия дней, статистика, карточки ключевых знаний, заметки, выбор темы оформления.

## Запуск на своём компьютере

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev      # сайт откроется на http://localhost:5173
npm run build    # готовая сборка появится в папке dist
```

## Публикация

Сайт публикуется на GitHub Pages автоматически при каждом изменении ветки `main`
(файл `.github/workflows/deploy.yml`). В настройках репозитория должно быть включено:
Settings → Pages → Source → GitHub Actions.

## Где что лежит

| Папка | Содержимое |
| --- | --- |
| `src/data` | Темы и курсы: тексты уроков, вопросы, карточки |
| `src/pages` | Страницы: главная, каталог, темы, курс, плеер, кабинет |
| `src/components` | Шапка, подвал, карточки, логотип, иконки |
| `src/lib` | Хранение прогресса и общие диалоги |
| `src/styles.css` | Дизайн-система: цвета, шрифты, компоненты |

Чтобы добавить урок, допишите объект в один из файлов `src/data/courses-*.js`.
Тема появляется в каталоге, когда в ней есть минимум два урока.

## Два вида уроков

**Сокращённый.** 65 уроков из 66. В них есть все шесть блоков, но текста на 5–7 минут чтения:
короткое вступление, список тезисов, один пример, три шага практики, три вопроса.
Образец: любой объект в `src/data/courses-d.js`.

**Полный.** Пока один: `src/data/lesson-decisions.js`, «Психология принятия решений».
Он рассчитан на 30 минут и помечен полем `full: true`, на сайте у него значок «Полный урок».
От сокращённого он отличается тремя вещами:

- вместо коротких списков в блоках стоит поле `body` — массив узлов
  `["p", текст]`, `["h", заголовок]`, `["ul", [...]]`, `["ol", [...]]`, `["note", подпись, текст]`,
  `["think", вопрос, разбор]` (вопрос с раскрывающимся ответом), `["code", текст]`,
  `["quote", текст, автор]`, `["table", шапка, строки, подпись]`;
- в практике есть рабочий лист `sheet`: поля, которые читатель заполняет, ответы сохраняются
  и показываются в кабинете;
- вопросов на закрепление пять, а не три.

Внутри текста работают две пометки: `**жирный**` и `` `код` ``.
Чтобы довести сокращённый урок до полного, перепишите его по образцу и поставьте `full: true`.

## Принятые решения

- Регион запуска: страны СНГ, язык русский. В уроках нет привязки к законам и валюте одной страны:
  суммы даны без названия валюты, уроки о праве учат навыку, а не нормам, и отсылают к местному закону.
- Монетизация: предварительно подписка. На сайте её пока нет, как и аккаунтов.
